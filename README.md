# Quiz Game

A Python-based quiz game where users answer questions to advance through stages and win prizes. This game is designed to be engaging and educational, providing a fun way to test knowledge on various topics.

## Features
- Multiple choice questions
- Scoring system to track player performance
- Stages that increase in difficulty

## Getting Started

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/quiz-game.git
   ```
2. Navigate to the project directory:
   ```bash
   cd quiz-game
   ```
3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

### Usage
To run the game, execute the following command:
```bash
python src/main.py
```
